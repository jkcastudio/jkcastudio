# JKCA Studio

Web, brand, and tooling studio in Southern California. In tech since 1999; shipping for a portfolio of ~50 clients across web, commerce, print, packaging, and photography.

Every site we ship has to beat the WordPress version we'd have built ten years ago, or it doesn't ship.

## The stack we ship on

Astro · Tailwind · Cloudflare (Workers, Pages, D1, Zero Trust) · Stripe (Checkout + Billing) · Playwright · Python tooling · local-first AI (Ollama)

The shop itself runs on an agent ops lane: nightly fleet checks with visual regression on every live site, a self-auditing toolkit, and playbooks that turn taste into named, enforceable rules.
